# DẤU VẾT — Real-Time Honeypot & SOC Monitoring System

A real-time cybersecurity monitoring system that captures and analyzes SSH activity using a Cowrie honeypot.

## Tech Stack

- Cowrie Honeypot
- Python Collector
- PostgreSQL
- FastAPI
- React + Vite
- Nginx
- Cloudflare Tunnel + Access
- MaxMind GeoLite2

## Features

- Real-time SSH event monitoring
- Source IP and geographic analysis
- SSH session and command tracking
- Security alert detection
- Responsive SOC dashboard
- Vietnamese / English interface

## Security

Credentials, private keys, raw attack logs, database backups and GeoLite2 database files are not included in this repository.
